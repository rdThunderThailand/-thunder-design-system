# Tailwind + shadcn/ui setup

The theme comes from `@rdthunderthailand/thunderone-theme` (generated from `tokens.json`). If the package cannot be installed, the same files are in `assets/code/tailwind/`.

## Setup

**Tailwind v4** (Lovable today: `@import "tailwindcss"` in `src/styles.css` or `src/index.css`)
1. `npm i @rdthunderthailand/thunderone-theme lucide-react`
2. Main CSS: `@import "tailwindcss";` then `@import "@rdthunderthailand/thunderone-theme/tailwind/v4.css";`.
3. Delete the project's own `:root { --background … }`, `.dark { … }` and `@theme inline { --color-… }` blocks, and any Inter/Geist font import. Keep `@plugin` / `@custom-variant` lines that are not about color.

**Tailwind v3** (`tailwind.config.ts` + `@tailwind` lines)
1. `npm i @rdthunderthailand/thunderone-theme lucide-react`
2. `tailwind.config.ts`: `presets: [require('@rdthunderthailand/thunderone-theme/tailwind/preset')]` (see `assets/code/tailwind/tailwind.config.example.ts`). Remove the project's own shadcn `colors` / `borderRadius` extend block.
3. `src/index.css`: `@import '@rdthunderthailand/thunderone-theme/tailwind/shadcn.css';` first, then the three `@tailwind` lines. Delete the old `:root` / `.dark` blocks.

Both produce the same class names (checked in CI with Tailwind 3 and 4). `components.json` can stay as generated by shadcn (`new-york`, `cssVariables: true`).

## Classes

| Need | Class |
|---|---|
| Page background / text | `bg-background text-foreground` |
| Card | `rounded-xl border border-border bg-card shadow-panel p-4` |
| Muted text / caption | `text-muted-foreground` |
| Row divider inside a card | `border-b border-border-subtle` |
| Primary button | shadcn `<Button>` (`h-10 rounded-lg bg-primary text-primary-foreground`) |
| Status badge | `bg-success-soft text-success` (also `warning`, `danger`, `info`; neutral `bg-muted text-muted-foreground`), or `t1Status[tone].badge` |
| Active nav item | `bg-primary-soft text-primary` |
| Text styles | `text-title-page`, `text-display-kpi`, `text-heading-section`, `text-title-card`, `text-body`, `text-body-sm`, `text-label-sm`, `text-label-xs`, `text-ui`, `text-caption-2xs`, `text-caption-9`, `text-caption-3xs`, `text-label-section uppercase`, `text-label-type uppercase` |
| Shell sizes | `w-sidebar`, `w-sidebar-collapsed`, `w-sidebar-drawer`, `h-header`, `max-w-search` |
| Long text measure | `max-w-measure` (720) |
| Elevation | `shadow-panel`, `shadow-float`, `shadow-dialog` |
| Modal scrim | `bg-overlay/60` |
| Charts | `bg-chart-1` … `bg-chart-5`, or `t1Tokens.color.chart1` in JS |
| Nav scroll area / swipe row / tabular numbers | `t1-scroll-quiet` / `t1-scroll-x` / `t1-num` |

Rules:
- Semantic classes only. No Tailwind default palette (`bg-blue-500`, `text-gray-600`), no arbitrary values (`bg-[#…]`, `text-[13px]`, `rounded-[6px]`) (DS-01, DS-02). The Lovable code still has a few literal sizes (`text-[9px]`, `text-[10px]`): replace them with the matching text style when you touch the file. Only allowed arbitrary value: `rounded-[4px]` on the checkbox and the `⌘K` kbd (design decision, no `radius/xs` token yet).
- shadcn components pick up the theme through the CSS variables. Add the `success` / `warning` / `danger` / `info` / `neutral` Badge variants with the soft classes above rather than new colors.
- Icons: `lucide-react` through `T1Icon` (`…/icons`) or the Workspace map (`…/workspaces/<key>`).
- Light theme only (DS-06). Delete shadcn's `.dark` block.
- Set `lang` on `<html>` so Thai line heights apply (DS-07).
